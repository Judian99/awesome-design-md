# 84 种风格幻灯片图鉴

以 NEOSPORIN® 止痛多肽抗菌软膏为共同主题，为 `design-md/` 中的 **84 个独立风格**分别制作一套 16:9 HTML 幻灯片。

## 打开方式

- 打开 [总览索引](index.html)，按分类或关键词筛选，点击封面进入对应示例。
- 也可以直接打开任意 `<风格目录>.html`，例如 [apple.html](apple.html)、[linear.app.html](linear.app.html) 和 [nintendo-2001.html](nintendo-2001.html)。
- 所有幻灯片均为独立单文件，无网络字体、图片、脚本或样式依赖；总览的封面图位于 `_previews/`。

### 查看器兼容性

- **默认无需 JavaScript 也能阅读**：脚本受限、被阻止，或窗口小于 640×360 时，四页会按顺序纵向排列并自动适配窄屏，直接滚动即可查看完整内容。
- **正常浏览器自动切换演示模式**：脚本可用时变为 16:9 单页放映，支持翻页、全屏和打印导出。
- 已修复查看器把窗口高度报告为 `0` 时画布被缩放成空白的问题。
- 若仍看到旧空白页，请刷新或重新下载离线包；完整交互建议使用 Chrome 或 Edge 打开。

每套包含 4 页，共 336 页：

1. 产品封面与核心价值
2. 四种活性成分
3. 用法与用量
4. 注意事项与储存

## 演示操作

| 操作 | 方式 |
|---|---|
| 下一页 / 上一页 | `→` / `←`，也支持上下方向键、PageUp、PageDown、空格 |
| 首页 / 末页 | `Home` / `End` |
| 指定页 | 点击底部圆点，或在 URL 末尾添加 `#1` 至 `#4` |
| 触屏翻页 | 左右滑动 |
| 全屏 | 按 `F` |
| 打印或导出 PDF | 点击右上角“打印 / PDF” |

打印样式会将 4 页全部展开为 16:9 页面，而不是只打印当前页。

## 文件说明

- `index.html`：可搜索、按分类筛选的 84 风格总览。
- `manifest.json`：风格名称、分类、文件、设计规范、版式和主色清单。
- `_previews/`：84 张 960×540 的封面预览图。
- `_build/group-*.json`：从各 `DESIGN.md` 提炼的配色、字体、圆角和风格配置。
- `_build/build.py`：批量生成独立 HTML 与索引。
- `_build/render_previews.py`：使用本机 Chrome 批量生成预览图。

重新生成：

```bash
python3 examples/style-slides/_build/build.py
python3 examples/style-slides/_build/render_previews.py --force
```

## 风格计数说明

`design-md/` 实际包含 84 个目录。原 [风格设计清单](../../风格设计清单.md) 曾将 VoltAgent 重复列在第 84 项并漏列 Superhuman；现已修正，因此本图鉴覆盖全部 84 个独立风格，包括 Superhuman。
